# 🎓 EduSync
**The Unified Synchronized Learning & Holistic Assessment Platform**

EduSync is a modern, high-fidelity Learning Management System (LMS) designed for seamless interaction between teachers and students. It prioritizes a premium user experience, real-time feedback, and automated administrative workflows.

---

## 🚀 Key Features

### 📝 Advanced Assessment Module
- **Manual Quiz Evaluation**: Teachers can now provide professional remarks and custom points for manually evaluated quiz questions.
- **Strict Time windows**: Quizzes are strictly accessible within teacher-defined start and end times, with informative toast-based feedback for students.

### 📅 Automated Attendance Tracking
- **Intelligent Status Logic**: Students are automatically marked "Late" after a 15-minute threshold, simplifying the teacher's live marking experience.
- **History Management**: Comprehensive session history with the ability to override attendance statuses via an intuitive dropdown interface.
- **Session Analysis**: Detailed session records including precise start/end times and calculated durations.

### 💎 Premium UI/UX & Design
- **High-Fidelity Components**: Custom-built interactive elements including dynamic datetime pickers, number togglers, and rich animation-enabled cards.
- **Standardized Feedback**: A consistent toast-based feedback system replaces intrusive UI disabling, ensuring a reactive and informative interface.
- **Glassmorphism & Aesthetics**: Modern, vibrant design language with glassmorphic elements and curated color palettes.

---

## 🛠️ Tech Stack

- **Frontend**: React (Vite), Redux Toolkit, Vanilla CSS (Premium Tokens), Lucide Icons, Framer Motion.
- **Backend**: Django REST Framework (DRF), PostgreSQL, Docker.
- **State Management**: Scalable Redux architecture with centralized toast and assessment handling.
